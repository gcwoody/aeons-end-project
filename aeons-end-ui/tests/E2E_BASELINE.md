# E2E 回归基线

## 基线范围

2026-10-13 的完整 Playwright 运行共有 201 项：184 项通过，17 项失败。现在从测试文件中移除了这 17 个失败用例，剩下的 184 项就是那次运行中通过的用例，作为后续开发的回归基线。它们分布在 39 个测试文件中。

后续改动应继续运行这些用例。若其中某项失败，应先查看具体失败步骤和浏览器截图，再判断是产品行为退化、测试脚本不稳定，还是预期行为已经改变。不要为了让测试变绿而直接删除或放宽基线断言；只有游戏规则或设计确实改变时，才更新对应测试。

## 运行方式

在 `aeons-end-ui` 目录运行：

```powershell
npm run test:e2e -- --workers=2
```

如果默认端口 `5173` 被占用，可以临时指定其他可用端口：

```powershell
$env:PLAYWRIGHT_BASE_URL = 'http://127.0.0.1:5175'
npm run test:e2e -- --workers=2
```
