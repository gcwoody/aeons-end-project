# 卡牌区域动效重构：批次 4 报告

状态：代码与文档已更新；验收尚未完成。

## 本批改动

- 删除旧的“比较动作前后卡牌数量来猜移动”的流程，包括 `resolveCardZoneTransfers()`、`resolveCardZoneMotion()`、区域数量/到达数量快照字段及其兜底调用。
- 棋盘卡牌飞行只按引擎移动记录和牌副 ID 找来源与落点。决策卡片也带牌副 ID，重复卡牌不会靠卡牌名称配对。
- 手牌、专属牌堆和棋盘区域的飞行动作共用移动 ID；已被一个队列接手的移动会被其他队列跳过。Supply 的获得继续使用引擎的创建记录。
- Control Bar 的手牌数字现在只读真实 `hand.length`。等待决策、暂留在手牌画面中的卡不再让数字多算 1。
- 更新 UI 开发指南与 Gallery 的动效说明；改写牌区转移回归用例，让它验证按牌副 ID 匹配。

旧来源快照仍会保留卡牌起点图片和飞行前的牌堆显示基线；它们只用于绘制飞行动画与逐张更新牌堆，不再推断哪张牌移动。牌堆显示投影也仍用于让计数和顶牌等到对应卡牌落地后再更新。
