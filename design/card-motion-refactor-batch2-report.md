# 卡牌区域动效重构：批次 2 报告

日期：2026-10-10  
范围：UI 动画展示、区域落点和统一计时；迁移手牌到弃牌堆、自己/盟友牌库顶，以及弃牌阶段。未开始批次 3。

## 完成内容

- UI 根据引擎记录的牌副移动来播放动画，不再靠比较动作前后的牌数猜哪张牌移动。同名牌用各自的牌副 ID 对应，避免两张同名牌串位。
- 每张牌起飞时，手牌画面同步收拢；弃牌堆/牌库保留旧顶牌和数量，直到该张牌落地后才更新。连续弃牌逐张更新。
- Woven Sky 的弃牌、效果选牌弃牌和牌库顶放置共用这条移动流程。弃牌阶段也改为通过引擎移动记录处理，不再直接改弃牌数组并另起一套飞行动画。
- 手牌飞向盟友牌库时，盟友的完整牌区不会同时显示，因此动画落到一直可见的盟友玩家栏；规则结果仍进入盟友牌库顶。
- 普通飞行和飞向牌库的翻面飞行共用时长配置。飞行卡牌保持原有宽高比。
- Playwright 使用自定义测试地址时，会在相同端口启动测试服务，避免误用另一个占用默认端口的服务。
