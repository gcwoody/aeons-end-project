# 卡牌区域动效重构：批次 3b

状态：已完成。

## 本批改动

- Supply 里的牌进入 Develop 区时，飞行动画会落到新牌的准确位置；Develop 区已有的牌会平滑挪开。
- 从 Develop 区获得的牌会飞进玩家弃牌堆。飞行结束前，弃牌堆顶牌和数量保持原样。
- 从 Supply 购买或获得的牌会飞到对应玩家牌区。引擎记录牌来自哪一叠 Supply，以及它最后进入哪个玩家牌区；相同卡牌也不会认错实例。
- 购买带有后续放置选择的牌时，飞行会等玩家选好目标后再继续。
