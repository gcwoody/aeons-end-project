# Aeon's End Digital Demo

## 中文

这是《Aeon's End》的非官方网页试玩版。目前由一名玩家控制两位 Mage，共同对抗 Nemesis。

在线游玩：[打开试玩页面](https://aeons-end-demo.xiaoas.xyz/)。

### Windows 本地游玩

1. [下载 friend-preview 项目压缩包](https://github.com/gcwoody/aeons-end-project/archive/refs/heads/friend-preview.zip)，并解压全部文件。
2. 双击项目根目录中的 `Play Aeon's End Demo.cmd`。
3. 游戏会自动在浏览器中打开。游玩时请保留弹出的命令窗口；关闭窗口即可停止游戏。

启动游戏不需要安装 Node.js 或 npm。卡牌图片从下载包中读取，以加快加载速度。存档保存在当前浏览器中。

## English

This is an unofficial browser demo of *Aeon's End*. One player controls both Mages as they work together to defeat a Nemesis.

Play online: [Open the demo](https://aeons-end-demo.xiaoas.xyz/).

### Play locally on Windows

1. [Download the friend-preview project ZIP](https://github.com/gcwoody/aeons-end-project/archive/refs/heads/friend-preview.zip) and extract all files.
2. Double-click `Play Aeon's End Demo.cmd` in the project folder.
3. The game opens in your browser. Keep the command window open while playing; close it to stop the game.

You do not need to install Node.js or npm. Card images load from the downloaded project files for faster access. Saves are stored in your browser.
