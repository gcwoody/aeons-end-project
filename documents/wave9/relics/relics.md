## Omen Loop

- Group: Relic
- Wiki: [Omen Loop](https://aeonsend.wiki.gg/wiki/Omen_Loop)
- Source template: `PlayerCard`

**Template fields**

- Cost: 3
- Develop Cost: 2
- Type: Relic
- Rules: When you Develop this, gain 2 pulse tokens.

Destroy this. Reveal the turn order deck. Return it in any order. You may lose 1 pulse token. If you do, any ally draws a card.
- Box 1: Beyond the Breach
- ID 1: BTB-1d-02 – BTB-1d-06
- Mechanics: Pulse Token

**Effect**

When you Develop this, gain 2 pulse tokens.

When you play this:
* Destroy this.
* Reveal the turn order deck. Return it in any order.
* You may lose 1 pulse token. If you do, any ally draws a card.

**Template fields**

- Cost: 4
- Develop Cost: 3
- Type: Relic
